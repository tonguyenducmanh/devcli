## td sys

Các tiện ích hệ thống (ls, cat, head, tail)

### Synopsis

Nhóm lệnh chứa các tiện ích thao tác với tệp tin và hệ thống, mô phỏng lại các lệnh quen thuộc trên Linux.

### Examples

```
  td sys ls
  td sys cat file.txt
  td sys head -n 5 file.txt
```

### Options

```
  -h, --help   hiển thị phần trợ giúp của lệnh này
```

## tm sys cp

Sao chép tệp hoặc thư mục

### Synopsis

Sao chép các tệp tin hoặc thư mục từ nguồn đến đích.

```
tm sys cp [nguồn...] [đích] [flags]
```

### Examples

```
  tm sys cp file1.txt file2.txt
  tm sys cp -r dir1 dir2
```

### Options

```
  -h, --help        hiển thị phần trợ giúp của lệnh này
  -r, --recursive   sao chép đệ quy thư mục
```

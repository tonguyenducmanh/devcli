## td sys grep

Tìm kiếm văn bản trong tệp

### Synopsis

Tìm kiếm các chuỗi văn bản khớp với biểu thức chính quy trong các tệp tin.

```
td sys grep [mẫu] [tệp...] [flags]
```

### Examples

```
  td sys grep "hello" file.txt
```

### Options

```
  -h, --help   hiển thị phần trợ giúp của lệnh này
```

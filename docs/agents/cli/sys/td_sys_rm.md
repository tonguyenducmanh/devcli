## td sys rm

Xoá tệp hoặc thư mục

### Synopsis

Xoá một hoặc nhiều tệp. Sử dụng cờ -r để xoá thư mục đệ quy.

```
td sys rm [tệp...] [flags]
```

### Examples

```
  td sys rm file.txt
  td sys rm -rf dir
```

### Options

```
  -f, --force       bỏ qua các lỗi không tồn tại
  -h, --help        hiển thị phần trợ giúp của lệnh này
  -r, --recursive   xoá đệ quy thư mục
```

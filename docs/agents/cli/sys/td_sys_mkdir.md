## td sys mkdir

Tạo thư mục mới

### Synopsis

Tạo một hoặc nhiều thư mục mới. Có thể sử dụng cờ -p để tạo đệ quy các thư mục cha nếu chưa tồn tại.

```
td sys mkdir [thư mục...] [flags]
```

### Examples

```
  td sys mkdir testdir
  td sys mkdir -p a/b/c
```

### Options

```
  -h, --help      hiển thị phần trợ giúp của lệnh này
  -p, --parents   tạo đệ quy các thư mục cha
```

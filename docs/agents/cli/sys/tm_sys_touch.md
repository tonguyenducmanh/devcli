## tm sys touch

Tạo tệp trống hoặc cập nhật thời gian

### Synopsis

Tạo một tệp tin trống nếu chưa tồn tại, hoặc cập nhật thời gian sửa đổi nếu đã tồn tại.

```
tm sys touch [tệp...] [flags]
```

### Examples

```
  tm sys touch file.txt
```

### Options

```
  -h, --help   hiển thị phần trợ giúp của lệnh này
```

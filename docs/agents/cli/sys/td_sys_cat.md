## td sys cat

In toàn bộ nội dung của tệp

### Synopsis

Đọc và in ra toàn bộ nội dung của một hoặc nhiều tệp văn bản.
Nếu không truyền tệp nào hoặc truyền '-' hệ thống sẽ đọc từ đầu vào chuẩn (stdin).

```
td sys cat [tệp...] [flags]
```

### Examples

```
  td sys cat file.txt
  td sys cat file1.txt file2.txt
```

### Options

```
  -h, --help   hiển thị phần trợ giúp của lệnh này
```

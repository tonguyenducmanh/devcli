## tm sys mv

Di chuyển hoặc đổi tên tệp

### Synopsis

Di chuyển hoặc đổi tên các tệp tin, thư mục từ nguồn đến đích.

```
tm sys mv [nguồn...] [đích] [flags]
```

### Examples

```
  tm sys mv file1.txt file2.txt
  tm sys mv file1.txt dir/
```

### Options

```
  -h, --help   hiển thị phần trợ giúp của lệnh này
```

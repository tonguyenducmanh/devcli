## td sys wc

Đếm số dòng, từ, ký tự

### Synopsis

Đếm và in ra số dòng, số từ và số byte của các tệp tin.

```
td sys wc [tệp...] [flags]
```

### Examples

```
  td sys wc file.txt
  td sys wc -l file.txt
```

### Options

```
  -c, --bytes   chỉ in số byte
  -h, --help    hiển thị phần trợ giúp của lệnh này
  -l, --lines   chỉ in số dòng
  -w, --words   chỉ in số từ
```

## td version

Hiển thị phiên bản của td

### Synopsis

In số phiên bản, hệ điều hành và kiến trúc máy đang chạy.

Thông tin này hữu ích khi báo lỗi, giúp biết bản dựng được biên dịch từ
phiên bản nào.

```
td version [flags]
```

### Examples

```
  td version
```
